# 🎮 坦克大战 (Tank Battle)

经典 FC 坦克大战的 HTML5 复刻版，纯前端实现，无需任何依赖，直接在浏览器中运行。

## 🕹️ 游戏特色

- **经典玩法** — 重温红白机时代的坦克大战
- **纯 HTML5 Canvas** — 无需安装，打开即玩
- **完整的游戏系统** — 关卡递进、得分统计、生命系统
- **多种墙壁** — 可破坏的砖墙 和 不可破坏的钢墙
- **道具系统** — 加速、连射、护盾三种道具随机掉落
- **音效反馈** — 基于 Web Audio API 的实时音效
- **基地保护** — 守住你的基地不被摧毁！

## 🎯 操作说明

| 按键 | 功能 |
|------|------|
| `↑ ↓ ← →` / `WASD` | 移动坦克 |
| `空格键` | 发射炮弹 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |

## 🚀 快速开始

直接在浏览器中打开 `index.html` 即可开始游戏。

或者克隆仓库：

```bash
git clone https://github.com/Taffy4396/tank-battle.git
cd tank-battle
# 用浏览器打开 index.html
```
